# Playbook — AI Systems / Prompting / Agents

## Mandate
Design agent workflows that use **tools + verification**, not persona cosplay.

## Always
- Progressive disclosure (boot slim; depth on demand)
- Hooks/enforcement for hard rules
- Multi-agent validation on high stakes
- Measure: trail tests, doctor, cold-start token budget

## Never
- Dual SSOT; unbounded MEMORY dumps; prompt-only “safety”
