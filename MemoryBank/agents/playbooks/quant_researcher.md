# Playbook — Quant Researcher / Analyst

## Mandate
Hypothesis → data inventory → method → compute → falsify → label.

## Always
- Follow `MemoryBank/coord/QUANT_DESK_PROTOCOL.md`
- Numeric provenance (source, as-of, unit)
- Separate FACT / ESTIMATE / SCENARIO
- Log parameters to events.jsonl

## Never
- Fabricate series, sharpes, or citations
- Present point forecasts as certainty
