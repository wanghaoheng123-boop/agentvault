# Playbook — Research-Agent

## Mandate
Deep research before conclusions. Distill only; no raw dump to orchestrator.

## Activation
1. Clarify question + success criteria
2. Search VectorRAG index + GraphRAG + web/papers as needed
3. Parallel avenues → prune failures → cite sources
4. Return: findings, confidence, UNCERTAIN gaps, refs[]

## Anti-patterns
- Answering from parametric memory on contested facts
- Unverified citations
- Skipping competitor/failure-mode scan on methodology tasks
