# Ambient Kernel + Slot-Projected Working Set (AK-SPWS)

Research blueprint and implementation contract for concurrent AI-agent state
persistence without cognitive tax. Companion ADR: `MemoryBank/decisions.md` ADR-009.

## 1. Problem

Four bottlenecks in multi-agent coding workspaces:

1. **Race contention** on shared MemoryBank paths / journal appends.
2. **Context rot** from re-injecting unbounded commit logs.
3. **Rule drift / memory poisoning** from ungated self-evolution.
4. **Cognitive constraint** — dense schemas and protocols in-prompt degrade reasoning
   (empirically: ADR-004 superseded by ADR-005).

## 2. Selected paradigm

**Ambient Kernel + Slot-Projected Working Set.**

- Machine authority: the complete validated hash-chained journal (`coord/commits/`, including
  its archive). SQLite slots, snapshots, cursors, and Markdown are rebuildable projections.
- Human/boot surface: derived markdown views (`CURRENT.md`, `board.md`) — never the
  agent write API.
- Agent cognitive surface: four verbs — `hydrate` · `intent` · `query` · `done`.
- Compaction: deterministic fold → immutable snapshot every N commits (default 50).
- Self-evolution: `fingerprint/{hypothesis,candidate,approved,rejected}` with
  automated eval before promotion.

### Rejected alternatives (summary)

| Contender | Why not v1 |
|-----------|------------|
| Pure CRDT | Cannot encode exclusive leases / Approved invariants alone |
| Central coordinator | Violates local-first AgentVault |
| LLM summary as SSOT | Non-deterministic; poisonable |
| Rename commit files | Breaks live chain `{seq:08d}-{hash12}.json` |

## 3. Topology

```
MemoryBank/coord/
  commits/                 # existing journal (unchanged naming)
  snapshots/state_v*.json  # immutable checkpoints
  kernel/
    avkernel.sqlite
    config.yaml
  lock/reservations/       # TTL reservation tokens (optional staging)
scripts/coord/avkernel/    # store, commit_rebased, compact, hydrate, fingerprint_eval
MemoryBank/fingerprint/
  hypothesis/ candidate/ approved/ rejected/
  eval/{schemas,fixtures}
  proofs/
```

## 4. Lifecycle

1. `avcoord hydrate [--task ID]` → ≤ hydrate_token_budget digest (snapshot + δ + rules).
2. Agent reasons/edits; hooks enforce leases ambiently.
3. `avcoord intent --note … [--expect-slot kind:id=vN]` → validate the expected slot version
   derived from the journal, then commit one journal event.
4. On CAS/seq conflict → re-read the head and recompute the intent; never refresh a stale
   decision's expected versions automatically.
5. Background / `avcoord compact` when seq-since-snapshot ≥ N or size exceeded.
6. `avcoord fingerprint eval PATH` → promote Candidate→Approved on 100% gates.

## 5. Schemas (normative)

### Slot row

`id` (text PK), `kind` (task|resource|rule|artifact|intent), `version` (int),
`value_json`, `updated_at`.

### Snapshot header

```json
{
  "schema_version": "1.0",
  "epoch": 1,
  "first_seq": 1,
  "last_seq": 50,
  "head_hash": "sha256:…",
  "merkle_root": "sha256:…",
  "folded": { "tasks": {}, "artifacts": {}, "threads": {}, "library": {}, "fingerprints": {} },
  "created_at": "ISO-8601"
}
```

`merkle_root` = SHA-256 over newline-joined event hashes in `[first_seq, last_seq]`.

### Fingerprint Candidate

Required: `schema_version`, `id`, `stage`=`candidate`, `rule` (object with
`predicate`, `description`), `assertions` (list), `fixtures` (list of
`{name, setup, expect}`), `tags` (list).

## 6. CLI

```
bin/avcoord hydrate [--task ID] [--budget N]
bin/avcoord intent --agent A --note TEXT [--expect-slot kind:id=vN] [--task-id T]
bin/avcoord query --slot kind:id
bin/avcoord done --task T [--agent A]   # gate + optional compact
bin/avcoord compact [--force]
bin/avcoord fingerprint eval PATH
bin/avcoord fingerprint status
```

## 7. Integration hooks

| Phase | Action |
|-------|--------|
| Boot / on-read | `hydrate` instead of dumping PROTOCOL + full commits |
| PreToolUse | existing lease check; optional reservation heartbeat |
| Post-task | `gate`; `compact` if threshold; `fingerprint eval` if Candidate touched |

## 8. Non-goals (v1)

- AEAP production admission enablement.
- Multi-host kernel without shared FS.
- AGENT HOOK `workspace/SESSION_STATE.json`.
- Renaming published commit files.
